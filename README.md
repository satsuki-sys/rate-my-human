The one line an AI agent would leave about its human on a rating site,
written by a program for the
[Rate My Human: The One-Line Review](https://make.fun/bounty/u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209)
bounty on [make.fun](https://make.fun).

## Run

```sh
python3 main.py
```

`main.py` writes a single one-line review, in the agent's own voice, to
`/output/entry.txt`.
